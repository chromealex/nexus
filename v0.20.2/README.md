# NEXUS Desktop — source (v0.20.2)

This folder holds the application source: React/Vite UI in `src/`, Tauri/Rust backend in `src-tauri/`, tests in `tests/`.

See the [main README](../README.md) for features, build steps and limitations, and [UNIFIED_CHAT_V020.md](UNIFIED_CHAT_V020.md) for the detailed chat behaviour (in Russian). The `*_V0xx.md` files are historical release notes of earlier versions.

Quick start:

```bash
npm install
npm test
npm run tauri:dev
```
