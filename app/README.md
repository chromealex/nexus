# NEXUS Desktop — app source

This folder holds the application: React/Vite UI in `src/`, Tauri/Rust backend in `src-tauri/`, tests in `tests/`.

See the [main README](../README.md) for features, build steps and limitations, [CHANGELOG](../CHANGELOG.md) for history, [UNIFIED_CHAT_V020.md](UNIFIED_CHAT_V020.md) for the detailed chat behaviour and [CHANNELS_V021.md](CHANNELS_V021.md) for task channels (both in Russian).

Quick start:

```bash
npm install
npm test
npm run tauri:dev
```
