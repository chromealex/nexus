# Отложенные задачи

## Общий Telegram-бот Nexus (отложено 14.11.2026)

Пользователь создал Telegram-бота и хочет, чтобы в Nexus его можно было подключить в один шаг, а свой бот оставался отдельной опцией.

Почему отложено: Telegram отдаёт обновления одного токена только одному получателю (`getUpdates` или webhook), поэтому общий бот для многих копий Nexus требует сервера-посредника. Токен нельзя вшивать в приложение — его извлечёт любой, кто скачал Nexus. Решили пока без сервера.

Что сделать, когда вернёмся:
- Выбрать хостинг посредника (Cloudflare Workers, VPS и т. п.).
- Посредник: webhook бота → привязка чата Telegram к установке Nexus по одноразовому коду (`/start КОД`) → очередь задач для каждой установки → ответы и `/allow КОД` обратно в Telegram. Токен бота — только на сервере.
- Nexus: вариант «Бот Nexus» в «Каналы → Telegram» (по умолчанию), привязка кодом, без ввода токена; «Свой бот» — текущий способ с токеном в связке ключей.
- Сохранить действующие правила каналов: список разрешённых отправителей, однократные `/allow`, старые сообщения при включении пропускаются.
